## REAPER Highlights

- **Track Routing:** REAPER track routing sends audio from one track to another, which is enough to learn a simple headphone mix.
- **Media Item:** REAPER media item is the block on the timeline, a take or a MIDI phrase you can move.
- **Action List:** REAPER action list lets you find a command and attach it to a key you remember.
- **Envelope:** REAPER envelope draws volume or pan changes across a media item.
- **Render:** REAPER render writes the small session out to a file you can play back in class or at home.

---

## What Is REAPER

REAPER is a flexible recorder and editor for home songs, podcasts, and study projects. REAPER media item is the thing you edit. REAPER track routing is how those items reach a mix you can hear. You can start with two tracks. A vocal memo and a simple backing are a complete first session in a bedroom or a dorm room.

REAPER envelope shapes loudness so a sentence is not suddenly harsh. REAPER action list keeps repeated edits on keys you choose, which helps when a class exercise asks for the same trim many times. REAPER render is the finish: one file from the session. The workspace stays useful for small work even though it can grow later.

Record or import one REAPER media item. Set REAPER track routing so you can hear it. Add a short REAPER envelope, look up one command in REAPER action list, and REAPER render a test file. If that file sounds like what you heard, the session is ready for a real short piece.

## Starting with REAPER

Prerequisites: A compatible computer, headphones, and permission to run REAPER.

1. **Prepare:** Create a project folder before you record.
2. **Add Items:** Place or record one REAPER media item on a new track.
3. **Route It:** Check REAPER track routing so the track reaches the main output.
4. **Shape Level:** Draw a simple REAPER envelope if one phrase is too loud.
5. **Learn One Key:** Find a split or play command in REAPER action list and assign it.
6. **Write A File:** Use REAPER render to make a short test you can play back.
